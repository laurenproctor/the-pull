# The Pull

Live prototype: https://thepullpartnerships.netlify.app

Working prototype for The Pull / Partner Studio + Collaboration Observatory.

## Deployment

This repository is intentionally configured as a static site.

- Production branch: `main`
- Build command: none
- Publish directory: `.`
- Entry point: `index.html`

Connect this repository to Netlify using **Import an existing project → GitHub**. Netlify will redeploy automatically whenever `main` changes.
